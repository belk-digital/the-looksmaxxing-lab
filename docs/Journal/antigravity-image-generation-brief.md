# Image Generation Brief — The Looksmaxxing Lab Journal (3 New Posts)

## Context

The Looksmaxxing Lab is a research-peptide e-commerce site (RUO / Research Use Only compounds). Three new journal (blog) articles were just added to the codebase and are fully coded and live, but they reference 15 image files that do not exist yet. Your job is to generate those 15 images and place them in the exact folder with the exact filenames below. No code changes are required — the site will automatically pick up any file placed correctly.

## Destination folder

Save every image to:

```
public/journal-images/
```

Relative to the project root: `f:\Belk Digital Projects\the-looksmaxxing-lab\public\journal-images\`

This folder already contains images for other, older posts — do not touch or rename any existing files in it. Only add the 15 new files listed below.

## File format & technical specs

- Format: **PNG**
- No visible text, letters, numbers, or logos baked into the image (AI image generators often render garbled text into diagrams — explicitly avoid this)
- No brand names, watermarks, or real company logos
- Style: clean, high-end editorial science/medical illustration — think a mix of pharmaceutical journal illustration and modern minimalist editorial photography. Color palette should lean into dark ink-blue and warm gold accents for abstract/diagram images, and cream/steel/neutral tones for photographic lab images.

| Image role | Minimum resolution | Aspect ratio |
|---|---|---|
| Hero banner (1 per post, 3 total) | 1920×1080 | 16:9 landscape |
| In-body image (4 per post, 12 total) | 1600×900 | 16:9 landscape |

Every image needs exactly the filename specified — filenames are case-sensitive and must match exactly, including hyphens, or the image will not display on the live site.
